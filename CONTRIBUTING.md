# Contributing

Bug reports and pull requests are welcome.

- Report problems under **Issues**. Please include your WordPress, PHP and MySQL/MariaDB versions, your host or local stack (LocalWP, Docker, MAMP and so on), and the message MoveKit shows.
- Code follows the WordPress coding standards. Run `phpcs` (see `phpcs.xml.dist`) before opening a pull request; the same check runs on GitHub.
- User-facing text must be translatable with the `movekit-migration-backup` text domain.
- Every REST route needs a `permission_callback`.
- MoveKit is GPL-2.0-or-later. By contributing you agree your work is released under the same license.

Security problems: please do not open a public issue. Contact the author through https://tawfiq.me.
